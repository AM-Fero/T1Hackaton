# Документация по платформе AI-собеседований

## Введение

Это полнофункциональное веб-приложение для автоматизации технических собеседований с использованием LLM. Система проводит технические собеседования с кандидатами, оценивает их ответы и предоставляет задания по программированию в режиме реального времени через чат-интерфейс.
Наш полный прототи представлен в фигме: https://www.figma.com/design/YbJJ2uEohK4nLn8TGa50Rn/%D0%A21-%D1%85%D0%B0%D0%BA%D0%B0%D1%82%D0%BE%D0%BD?node-id=0-1&t=y5hvyijtIcQB17nO-1

## Архитектура

### Бэкенд (Flask/Python)
- **Фреймворк**: Flask с поддержкой CORS
- **База данных**: PostgreSQL
- **Интеграция с ИИ**: OpenAI-совместимое LLM API от SciBox
- **Выполнение кода**: Docker-контейнеры для запуска Python кода
- **Управление сессиями**: Хранилище сессий в памяти с автоматической очисткой

### Фронтенд (HTML/JavaScript)
- **Интерфейс**: Чат в реальном времени с интегрированным редактором кода
- **Редактор**: Monaco Editor (компонент редактора VS Code)

## API Эндпоинты

### Управление вакансиями
- `POST /vacancies` - Создание новой вакансии
- `GET /vacancies` - Список всех вакансий
- `GET /vacancies/<hash>` - Получение вакансии по хешу
- `GET /vacancy/<hash>` - Рендеринг страницы вакансии

### Сессии собеседования
- `POST /api/start-interview` - Начало новой сессии собеседования
- `POST /api/chat` - Отправка сообщения в собеседовании
- `GET /api/session/<id>` - Получение информации о сессии
- `DELETE /api/session/<id>` - Удаление сессии

### Выполнение кода
- `POST /api/execute-python` - Выполнение Python кода
- `POST /api/get-task` - Получение задания по программированию

## Процесс собеседования

1. **Подача заявки**: Кандидат заполняет форму заявки
2. **Создание сессии**: Система создает сессию собеседования с контекстом
3. **Теоретическая фаза**: ИИ задает технические вопросы
4. **Оценка**: ИИ оценивает качество и полноту ответов
5. **Фаза программирования**: Кандидат решает задания по программированию
6. **Выполнение кода**: Система запускает и проверяет код
7. **Завершение**: Собеседование заканчивается после всех вопросов

## Конфигурация

### Требования к окружению
- База данных PostgreSQL (T1-Interview.sql)
- Docker для выполнения кода

### Ключевые конфигурационные файлы
- `dbconfig.json` - Настройки подключения к базе данных
- HTML шаблоны для рендеринга фронтенда

## Установка и настройка

1. **Установка зависимостей**
   ```bash
   pip install -r requirements.txt
   ```

2. **Настройка базы данных**
   - Создайте базу данных PostgreSQL
   - Настройте подключение в `dbconfig.json`
   - Восстановите базу из образа T1-interview.sql

3. **Конфигурация**
   - Укажите API ключ в `server.py` 16 строчка
   - Запустите Docker

4. **Запуск приложения**
   ```bash
   python server.py
   ```

## Процесс использования

### Для HR/Рекрутеров
1. Создайте вакансию через `/vacancies` POST endpoint
2. Поделитесь сгенерированным хеш-URL с кандидатами

### Для Кандидатов
1. Перейдите по предоставленному URL вакансии
2. Заполните форму заявки
3. Участвуйте в AI-собеседовании

4. Решайте задания по программированию в интегрированной IDE
